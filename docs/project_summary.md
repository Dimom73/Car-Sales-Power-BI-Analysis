# Project Summary

## Project Name

Car Sales Power BI Analysis

## Project Type

Power BI dashboard and business intelligence analysis.

## Objective

The goal of this project was to analyze car sales performance using a full car sales dataset.

The analysis focuses on total sales, sales count, average price, company performance, car characteristics, customer profile, dealer performance, regional performance, and sales trends over time.

## Business Questions

The report was designed to answer these questions:

1. What is the overall sales performance?
2. How do total sales and sales count change over time?
3. Which car companies and models perform better?
4. Which car characteristics are more common in the sales data?
5. How do customer groups relate to sales performance?
6. Which dealer regions and individual dealers perform best?
7. What future sales direction is suggested by the historical trend?

## Dataset

The dataset contains 23,906 individual car sale transactions with 16 columns.

Each row represents one completed car sale and includes information about the customer, car, dealer, and transaction.

## Main Workflow

1. Imported the original CSV dataset into Power BI.
2. Checked column names, data types, duplicate values, and missing values.
3. Created clean dimension tables and a sales fact table.
4. Built relationships between fact and dimension tables.
5. Created DAX measures for key business metrics.
6. Designed interactive report pages.
7. Added slicers for filtering by time, company, dealer region, and customer attributes.
8. Added forecast analysis to estimate possible future sales direction.

## Main Outputs

- Interactive Power BI report
- Star schema data model
- KPI measures
- Time-based sales analysis
- Company analysis
- Car characteristics analysis
- Customer analysis
- Dealer and region analysis
- Forecast visual
